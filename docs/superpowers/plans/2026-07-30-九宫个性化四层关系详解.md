# 九宫个性化四层关系详解 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不重做现有三 Tab 网页结构的前提下，基于九宫资料全集和线上 v6 字段生成可追溯、确定性、无需老师二次解释的上层／自我／下层／对外年度详解，并删除五类问询的重复尾注。

**Architecture:** 先把 LifeOS 九宫资料包转成只读清单、文本索引和规则依据矩阵，再用独立纯函数将 `JiugongFull + YearEnvironment` 映射为四层结构化详解。页面只渲染结构化结果；五类问询保留主题分析但不再拼接四层环境策略。

**Tech Stack:** TypeScript、Next.js 16、React、Vitest；资料提取使用现有工作区文档/PDF/表格能力和系统媒体工具，不新增运行时依赖。

## Global Constraints

- 不调用生成式 AI；同一输入必须返回完全一致的结果。
- 计算只使用线上 v6 API；不修改 v6 算法与康熙字库。
- 所有解释必须能追溯到 `LifeOS/20-29 工作事业/24.01 灵魂解码运营/九宫人生解码/` 内列示资料。
- 未获资料支持的组合不推断，返回明确的边界说明。
- 保留现有特质分析、经营环境、经营分析、年份选择、五类问询与 90 年卷轴结构。
- 不存储姓名和生日，不新增日志或数据库写入。
- 报告应让普通测评人无需专人讲解即可理解。
