# 九宫 v6 API 收编与产品升级 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将九宫 v6 字节级迁至站内无状态 API，并用蓝本产品层升级三 Tab、流年联动、五类问询、27 条策略和打印体验。

**Architecture:** 服务端专用模块持有 v6 算法、S2T 与康熙字库，`POST /api/jiugong/v6` 是唯一计算入口。客户端只负责校验、请求、会话暂存与渲染；经营环境和问询只消费 API 返回的逐年结果，不复制任何计算公式。

**Tech Stack:** Next.js App Router、React 19、TypeScript、Vitest、Node.js runtime、Tailwind CSS

## Global Constraints

- 现有 v6 算法只搬迁，不重写、不优化公式、不改变字段含义。
- 王献科必须保持总笔画 33、局差 0；`献→獻` 必须保持 13 画转 20 画。
- API 无状态；姓名生日不落库、不写日志、不进入错误文本。
- 前端不得保留 `calcFull`、康熙字库或第二条计算路径。
- 不修改 `.env`，不安装新依赖，不自行部署；部署只经 Hermes。
- 保留并不触碰仓库现有未跟踪目录 `.next.old-0727b/`。

```ts
export async function requestJiugongV6(
  input: JiugongInput,
  fetcher: typeof fetch = fetch,
): Promise<JiugongFull> {
  const response = await fetcher('/api/jiugong/v6', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(input),
  });
  const payload = await response.json();
  if (!response.ok || !payload.success) {
    throw new Error(payload.error || '排盘暂时不可用，请稍后重试');
  }
  return payload.data;
}
```
