# SoulCode 内页安静编辑风视觉规格

## 目标

在不改变现有数据、API、登录、报告生成、保存和打印功能的前提下，统一 SoulCode 内页的字号、间距、表单、报告阅读和移动端视觉，让人生总览、关系合盘、人类图等页面更接近见己学园的安静、舒展和有呼吸感的阅读体验。

## 设计方向

采用“见己式安静编辑风”：暖米白为底，深棕为正文，深金作为主强调色，使用低对比度的浅色表面和留白建立层级，避免用连续边框堆叠信息。

## 视觉规则

- 正文和控件使用稳定的系统中文无衬线字体；霞鹜文楷只用于展示标题、引用和少量品牌文字。
- 页面标题：桌面端 42–48px，移动端 30–34px；正文 14–16px；辅助标签不低于 11px。
- 表单页面使用 1080–1180px 的舒展内容宽度，桌面端采用“说明 + 表单”双栏，移动端单栏。
- `.card-jade` 不再作为所有内容的默认容器；输入区使用轻表面和留白，只有独立结果模块保留卡片边界。
- 输入控件取消厚重阴影；保持可见焦点状态、键盘操作和禁用状态。
- 页面屏幕端的 Markdown 表格取消密集竖线，保留轻量底部分隔和交替背景；打印端继续保留完整表格边界。
- 主 CTA 使用纯色深金，不使用渐变文字或渐变按钮。
- 保留现有所有组件、字段、请求地址、报告内容和打印入口。

## 页面范围

1. `/master-report`：输入页、骨架结果、完整报告区块。
2. `/compatibility`：关系类型切换、多人输入表单、结果阅读区。
3. `/human-design`：输入页、结果分区、知识问答和 AI 解读区。
4. 共享报告表格、输入控件、卡片和页面标题系统。
5. 移动端断点和屏幕/打印媒体规则。

## 不在本次范围

- 不修改后端计算、模型提示词、SSE 流程、账号系统和收费逻辑。
- 不修改 Stella 和见己学园的线上代码。
- 不在本地展示稿验收前部署生产服务器。

## 图表展示升级（2026-08-09 补充）

本次采用“古典图谱骨架 + 现代专业信息层”的 C 方案。图表全部使用原创、数据驱动的 SVG/HTML 组件，不直接嵌入或热链本机参考图；本机的人类图、八字、紫微图片只用于观察信息层级、留白和标注方式。

### 人类图

- 保留九大中心、通道、闸门的真实数据关系，不改变排盘结果。
- 重画为高比例、可缩放的 BodyGraph；已定义中心使用低饱和暖色，开放中心使用纸白和细线，不再使用深色大底。
- 图表旁增加类型、策略、内在权威、人生角色、定义等摘要信息，避免用户只看到一张“看不懂的图”。
- 闸门数字采用分层标注：重要激活闸门清晰显示，其余信息不挤占主体图形；移动端改为图表后置入可折叠信息栏。
- 若增加红黑设计/人格栏，使用原创排版和文字信息，不复制第三方商业图表图片。

### 八字

- 四柱改为四根完整立柱：年柱、月柱、日柱、时柱统一宽度和纵向节奏。
- 天干、地支、十神/辅助信息分层展示；日主单独加轻金色焦点标识。
- 五行分布改为横向比例条与简短图例，避免当前深灰背景和过小的底部文字。
- 预留藏干、纳音、大运等信息的扩展位，但本轮只展示现有数据，不能为了填版面制造数据。

### 紫微斗数

- 保留十二宫结构，改为高对比度的“命盘图谱”布局。
- 命宫、身宫、财帛、官禄等核心宫位使用轻量重点色，其余宫位保持安静层级。
- 每宫默认显示宫名和最重要的少量星曜，详细星曜信息进入展开区，解决小屏拥挤问题。
- 中心区显示命主、身主、五行局等已有信息；本命与运限信息分开，避免混排。

### 五运六气

- 将“出生年运”和“出生气化”设计为一张紧凑的双指标摘要卡。
- 通过季节/阴阳/五行的原创线性图形增强识别度，但不虚构当前 API 没有返回的解释数据。
- 卡片高度随内容收缩，消除截图中的大面积空白。

### 布局与验收

- 四图不再机械使用等宽两列：人类图与八字作为主视觉区，紫微与五运六气作为辅助区；窄屏统一单列。
- 屏幕端使用轻边界和留白，打印端保留必要边界与高对比度，保证 PDF 可读。
- 验收必须覆盖：桌面 1280×900、手机 390×844、A4 PDF；检查中文字体、图表比例、文字溢出、横向滚动、报告下载和现有数据字段。

## 验收标准

- 上述三个核心内页在桌面端和手机端无标题重叠、无横向溢出、无密集表格网格。
- 输入字段仍能正常填写和提交，成功/失败/等待状态仍可见。
- 报告内容、Markdown 标题、列表、表格和图表仍完整显示。
- 屏幕阅读比当前版本更少边框、更清楚的字号层级和更宽松的段落间距。
- 打印版保留 A4 可读性，不把屏幕端的无边框策略错误带入打印表格。
