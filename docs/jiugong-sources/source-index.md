## 采用原则

1. 年度事实以线上 v6 返回的气场、能量、岁值星、运组和碰撞为准。
2. 个人承接只组合资料明确关联的局、质、五行、主副功能和管理风格。
3. 对外关系没有独立碰撞周期，不生成对外碰撞结论。
4. 同一概念发生冲突时，以批准裁决、技术规格和 K3 验收口径优先。
5. 无明确来源的组合输出边界说明，不使用玄断补位。
